## SELAH 기준기 (PC 프로그램)

SELAH RTA 앱의 「PC 측정 마이크」에 쓰는 Windows 프로그램입니다. PC 에 연결한 오디오 인터페이스와 측정 마이크를, 같은 공유기(Wi‑Fi)에 있는 휴대폰의 SELAH RTA 앱에서 측정 기기로 사용할 수 있게 합니다.

- 내려받기·사용 안내: https://joaworks.com/support/#pc-download
- 파일은 [Releases](../../releases/latest) 에 있습니다.
  - `SELAH-Ref-32bit.exe` — 32비트·64비트 Windows 모두(모르면 이것)
  - `SELAH-Ref-64bit.exe` — 64비트 Windows 전용
- Windows 7 · 8 · 10 · 11
